# 任务 1：工程骨架与夹具

完成日期：2026-11-17。环境是 Windows 上的 Python 3.11.9，虚拟环境为 `.venv-task4`。

## 做了什么

安装任务四依赖，固定夹具路径，并生成一段只用于接口和延迟测试的 1080p 视频。

已安装的关键版本：PyTorch 2.15.0、Ultralytics 8.3.253、ONNX Runtime 1.32.0、OpenCV 5.0.0.93。

## 文件

| 路径 | 作用 |
| --- | --- |
| `requirements-task4.txt` | 依赖范围 |
| `.venv-task4/` | Python 3.11 虚拟环境 |
| `tests/fixtures.py` | 样例、冒烟视频、1080p 夹具和 seed 42 随机数 |
| `tests/__init__.py` | 让本地 `tests` 优先于 Ultralytics 安装进虚拟环境的同名包 |
| `tests/test_contracts.py` | 当时写入 5 项夹具测试，任务 2 又追加了合同测试 |
| `artifacts/fixtures/ten-second-1080p.mp4` | 1920×1080、250 帧、25 fps |
| `artifacts/fixtures/_write_ten_second_1080p.py` | 用 seed 42 重写该视频的脚本 |
| `artifacts/reports/fixture-hashes.json` | 视频 SHA-256 和尺寸 |

`tests.fixtures` 指向：

- `任务一模型/demo/samples/` 下 6 张 jpg
- `任务三模型/data/raw/task3-smoke/engineering-smoke-10s.avi`
- `artifacts/fixtures/ten-second-1080p.mp4`

1080p 视频 SHA-256：`7d81e59fd4c94ae31d52adea0475a6b2e092cadaabbea7769d467bb40af09172`。画面由 seed 42 决定，没有检测真值。
