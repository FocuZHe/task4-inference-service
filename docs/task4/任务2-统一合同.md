## 合同

请求和响应都包含 `modelVersion`、`requestId`、`source`、`receivedAt`、`result`、`latencyMs`、`errorCode`。未知字段拒绝。`receivedAt` 必须带时区。`source` 固定为 `eo`。

输入只能是 `imageBase64`、`framesBase64`、`videoBase64` 中的一种。批量帧数量为 1 到 8。图片解码后长边不超过 1920。

检测框字段为 `bboxXyxy`、`label`、`confidence`、`imageWidth`、`imageHeight`。`label` 只能是 `drone`、`bird`、`aircraft`、`unknown`。

画质结果使用 `shared.video-quality/1.0` 的字段。`freeze_suspected` 的状态只能是 `suspected`。

错误响应仍保留七个顶层字段。HTTP 状态对应关系：

| errorCode | HTTP |
| --- | --- |
| `INVALID_INPUT` | 400 |
| `MODEL_MISSING` | 503 |
| `TIMEOUT` | 408 |
| `CANCELLED` | 429 |
| `QUEUE_FULL`、`UNAVAILABLE` | 503 |
| `RESOURCE_EXHAUSTED`、`INTERNAL` | 500 |
