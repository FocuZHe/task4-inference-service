# 任务 8：故障注入

完成日期：2026-11-18。

## 做了什么

为六种故障各写了一个测试。服务进程没有因为这些请求退出。`create_app(registry, runtimes, limits)` 可以注入注册表、检测运行时和限流，测试不加载随机森林。

模型文件缺失的 HTTP 状态从合同初稿的 404 改为 503，与就绪检查和故障表一致。响应里的 `errorCode` 仍是 `MODEL_MISSING`。

## 文件

| 路径 | 作用 |
| --- | --- |
| `tests/test_faults.py` | 六种故障 |
| `serving/app.py` | `runtimes` 注入参数 |
| `serving/contracts.py` | `MODEL_MISSING` 对应 503 |

## 结果

| 注入 | 结果 |
| --- | --- |
| 活动模型文件不存在 | 推理 503 `MODEL_MISSING`，`/ready` 也是 503 |
| 图片 base64 不是图像 | 400 `INVALID_INPUT` |
| 运行时间超过 `timeoutS` | 408 `TIMEOUT` |
| 运行时抛出内存错误 | 500 `RESOURCE_EXHAUSTED` |
| 队列里已有 4 个未完成请求 | 503 `QUEUE_FULL` |
| 重建应用，模拟重启 | `/health` 为 200；登记哈希仍匹配时 `/ready` 为 200 |
