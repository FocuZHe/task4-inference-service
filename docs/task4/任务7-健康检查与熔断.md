# 任务 7：健康检查、熔断和 Prometheus

完成日期：2026-11-18。

## 做了什么

加上健康检查、就绪检查、熔断和 Prometheus 指标。就绪检查调用 `ModelRegistry.verify_active()`，用登记的 SHA-256 核对活动模型文件，不把现场新算的哈希写成期望值。

## 文件

| 路径 | 作用 |
| --- | --- |
| `serving/health.py` | 连续 5 次内部错误或内存错误后熔断，30 秒后放行一个探测请求 |
| `serving/app.py` | `GET /health`、`GET /ready`、`GET /metrics` |
| `serving/model_registry.py` | `verify_active` |
| `tests/test_api.py` | 熔断、半开、健康、就绪和指标 |

## 行为

`/health` 在进程活着时返回 200 `{"status":"ok"}`。活动模型缺失时 `/ready` 返回 503 `MODEL_MISSING`。

连续 5 次运行时异常返回 500 `INTERNAL`。第 6 次在模型仍存在时返回 503 `UNAVAILABLE`。时钟走过 30 秒后，一个成功请求让熔断关闭。

指标包括 `inference_latency_ms`、`queue_wait_ms`、`inference_errors_total`、`process_rss_bytes` 和 `gpu_memory_bytes`。这台机器没有 NVIDIA GPU，`gpu_memory_bytes` 为 0。
