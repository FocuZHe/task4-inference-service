# 任务 6：三种推理接口和限流

完成日期：2026-11-18。

## 做了什么

加上单帧、批量帧和连续视频三个接口，以及超时、取消、队列长度和并发限制。测试注入假的检测运行时，不加载 355 MB 的随机森林。

## 文件

| 路径 | 作用 |
| --- | --- |
| `serving/limits.py` | 默认长边 1920、队列 4、并发 2、超时 2 秒 |
| `serving/inference.py` | 解码、排队、取消、检测或画质评分 |
| `serving/app.py` | `POST /infer/frame`、`/infer/batch`、`/infer/video`、`/infer/cancel/{requestId}` |
| `serving/contracts.py` | 增加 `fixtureId`，批量结果使用 `frames` |
| `tests/test_api.py` | 合同字段、8 帧、1080p 夹具、超大图、队列满、超时 |

`task` 查询参数选择 `detection` 或 `quality`，默认是检测。视频可以传 `videoBase64`，也可以传已登记的 `fixtureId`：`ten-second-1080p` 或 `engineering-smoke-10s`。

## 验证

```powershell
.\.venv-task4\Scripts\python.exe -m pytest tests/test_api.py -v
```

任务六相关结果：单帧返回七个合同字段且 `errorCode` 为空；8 帧返回 8 个结果；1080p 夹具至少一帧；1921 像素长边返回 400 `INVALID_INPUT`；队列容量 4 时再来的排队请求返回 503 `QUEUE_FULL`；超时返回 408 `TIMEOUT`。
